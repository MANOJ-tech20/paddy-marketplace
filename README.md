# Paddy Market – Agricultural Marketplace

## Project Overview
Paddy Market is a sample agricultural marketplace website for exploring agricultural products such as paddy, seeds, pulses, compost, and farming tools.

This project is built to practise web development and DevOps fundamentals.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Git and GitHub
- GitHub Actions
- HTMLHint

## Features
- Browse sample agricultural products
- Search, filter, and sort products
- Demonstration shopping cart
- Farmer submission and feedback forms
- Rule-based chatbot
- Responsive website interface

## Automated Checks
GitHub Actions automatically checks:
- Required website files
- Basic HTML structure
- JavaScript syntax
- Automated product tests
- HTMLHint validation

## Run Locally
Clone the repository:

```bash
git clone https://github.com/MANOJ-tech20/paddy-marketplace.git
```

Open the project folder and launch `index.html` in your browser.

Run the product tests with Node.js:

```bash
node --test tests/products.test.js
```

## Important Note
This is a learning project. Product listings and prices are sample data. The cart and forms are demonstrations, not a production ordering system.
